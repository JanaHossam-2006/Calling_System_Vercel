### تنظيف البيانات القديمة (اختياري)
إذا أردت توحيد البيانات القديمة:

```javascript
// السكريبت التالي يحول جميع "لم يرد اطلاقا" إلى "لم يرد"
function updateOldStatuses() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('البيانات');
  const data = sheet.getDataRange().getValues();
  const headers = data[0];
  const statusCol = headers.indexOf('الحالة - العميل');
  
  let updateCount = 0;
  for (let i = 1; i < data.length; i++) {
    if (data[i][statusCol] === 'لم يرد اطلاقا') {
      sheet.getRange(i + 1, statusCol + 1).setValue('لم يرد');
      updateCount++;
    }
  }
  
  return `تم تحديث ${updateCount} طلبية`;
}
```

**تحذير:** قبل تشغيل السكريبت أعلاه، تأكد من عمل نسخة احتياطية من الشيت!
