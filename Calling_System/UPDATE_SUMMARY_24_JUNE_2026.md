## ✅ 3. إضافة نظام التابات للموظفين 🎯

### الميزة الجديدة
تم إضافة 3 تابات لواجهة الموظفين لتسهيل الوصول للطلبات:

#### 🔵 كل الطلبات (افتراضي)
- يعرض جميع الطلبات
- يفتح تلقائياً عند الدخول
- Badge أزرق بالعدد الكلي

#### 🔴 بدون حالة
- الطلبات التي لم يتم تحديد حالة العميل فيها
- إشعار أحمر للفت الانتباه
- أولوية قصوى (طلبات جديدة)

#### 🟠 بانتظار الشحن
- حالة العميل = "رد و يستلم"
- حالة الشحنة فارغة
- بدون "مرتجع" أو "مؤجل" أو "مراجعه"
- إشعار برتقالي
- تحتاج متابعة مع المندوب

### التصميم
```
┌──────────────────────────────────────────────────────────┐
│ [كل الطلبات 50] [بدون حالة 🔴 5] [بانتظار الشحن 🟠 3] │
└──────────────────────────────────────────────────────────┘
```

### الإشعارات (Badges)
- **عدد > 0:** خلفية ملونة + ظل
- **عدد = 0:** خلفية رمادية + رقم "0"

### البحث
- **للموظفين:** يبحث في **كل الطلبات** (بغض النظر عن التاب)
- **للمتاجر:** يبحث في **التاب الحالي** فقط

### الملف المعدل
- `JavaScript.html`
  - إضافة `currentEmployeeTab: 'all'` في state
  - إضافة دالة `switchEmployeeTab()`
  - إضافة منطق التابات في `renderDashboard()`
  - تعديل منطق البحث
