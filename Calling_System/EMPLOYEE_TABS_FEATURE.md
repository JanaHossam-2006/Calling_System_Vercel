# ميزة التابات للموظفين

## التاريخ
24 يونيو 2026

## نظرة عامة
تم إضافة نظام تابات (تبويبات) لواجهة الموظفين لتسهيل الوصول للطلبات حسب حالتها، مع إشعارات ملونة للفت الانتباه للطلبات التي تحتاج متابعة فورية.

---

## 🎯 التابات الجديدة

### 1️⃣ كل الطلبات (All Orders)
- **الوصف:** يعرض جميع الطلبات بدون فلترة
- **الأيقونة:** 📋
- **اللون:** أزرق (Indigo)
- **الافتراضي:** ✅ هذا هو التاب الذي يفتح تلقائياً عند الدخول

### 2️⃣ بدون حالة (No Status)
- **الوصف:** الطلبات التي حالة العميل فيها فارغة (لم يتم تحديدها)
- **الأيقونة:** ⚠️
- **اللون الإشعار:** أحمر 🔴 (#ef4444)
- **الأولوية:** عالية جداً (طلبات جديدة تحتاج اتصال)
- **الشرط:**
  ```javascript
  !order['الحالة - العميل'] || order['الحالة - العميل'].trim() === ''
  ```

### 3️⃣ لم يرد (No Answer) - **محدّث!**
- **الوصف:** الطلبات التي حالة العميل = "لم يرد"
- **الأيقونة:** 📞
- **اللون الإشعار:** أصفر 🟡 (#eab308)
- **الأولوية:** عالية (تحتاج متابعة ورجوع)
- **الشرط:**
  ```javascript
  order['الحالة - العميل'] === 'لم يرد'
  ```

### 4️⃣ بانتظار الشحن (Pending Shipment)
- **الوصف:** الطلبات الجاهزة للشحن لكن لم يتم التواصل مع المندوب بعد
- **الأيقونة:** 🚚
- **اللون الإشعار:** برتقالي 🟠 (#f97316)
- **الأولوية:** متوسطة (تحتاج متابعة مع المندوب)
- **الشروط:**
  ```javascript
  order['الحالة - العميل'] === 'رد و يستلم' &&
  !order['الحالة - الشحنه'] &&
  !order['ملاحظة'].includes('مرتجع') &&
  !order['ملاحظة'].includes('مؤجل') &&
  !order['ملاحظة'].includes('مراجعه')
  ```

## 🎨 التصميم

### شكل التابات
```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [كل الطلبات 50] [بدون حالة 🔴 5] [لم يرد 🟡 8] [بانتظار الشحن 🟠 3] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### الإشعارات (Badges)
- **إذا العدد > 0:**
  - خلفية ملونة حسب التاب:
    - أحمر 🔴 لـ "بدون حالة"
    - أصفر 🟡 لـ "لم يرد"
    - برتقالي 🟠 لـ "بانتظار الشحن"
    - أزرق 🔵 لـ "كل الطلبات"
  - ظل ملون (shadow) لزيادة الوضوح
  - خط عريض (font-weight: 800)
  
- **إذا العدد = 0:**
  - خلفية رمادية شفافة
  - بدون ظل
  - يظهر "0" بلون رمادي فاتح

### حالات التاب
- **نشط (Active):** خلفية زرقاء، نص أبيض
- **غير نشط (Inactive):** خلفية شفافة، نص رمادي، حدود رمادية

## 🔍 البحث

### السلوك
- **للموظفين:** البحث يشتغل على **كل الطلبات** بغض النظر عن التاب المختار
- **للمتاجر:** البحث يشتغل على **التاب الحالي** فقط

### مثال
إذا الموظفة في تاب "بدون حالة" وبحثت عن كود طلبية:
- ✅ سيظهر الطلب حتى لو مش في تاب "بدون حالة"
- ✅ البحث يفتش في جميع الطلبات

## 💻 التعديلات التقنية

### 1. State Management
```javascript
window.state = {
    // ... existing properties
    currentEmployeeTab: 'all' // 'all', 'no_status', 'pending_shipment'
};
```

### 2. دوال جديدة
```javascript
window.switchEmployeeTab = (tabName) => {
    state.currentEmployeeTab = tabName;
    renderDashboard();
};
```

### 3. منطق الفلترة
```javascript
// في دالة renderDashboard()
if (state.userRole === 'employee') {
    // حساب الطلبات لكل تاب
    const noStatusOrders = allOrders.filter(o => !o['الحالة - العميل']);
    const pendingShipmentOrders = allOrders.filter(o => {
        // شروط "بانتظار الشحن"
    });
    
    // تحديد sourceOrders بناءً على التاب
    if (state.currentEmployeeTab === 'no_status') {
        sourceOrders = noStatusOrders;
    } else if (state.currentEmployeeTab === 'pending_shipment') {
        sourceOrders = pendingShipmentOrders;
    } else {
        sourceOrders = allOrders;
    }
}
```

## 🧪 اختبار الميزة

### سيناريو 1: التاب الافتراضي
1. سجل دخول كموظفة
2. ✅ تأكد من فتح تاب "كل الطلبات" تلقائياً
3. ✅ تأكد من ظهور جميع الطلبات

### سيناريو 2: تاب "بدون حالة"
1. أضف طلبية بدون حالة عميل
2. ✅ يجب ظهور إشعار أحمر 🔴 بجانب "بدون حالة"
3. اضغط على التاب
4. ✅ يجب ظهور الطلبات بدون حالة فقط

### سيناريو 3: تاب "بانتظار الشحن"
1. أضف طلبية بحالة "رد و يستلم" وبدون حالة شحنة
2. ✅ يجب ظهور إشعار برتقالي 🟠 بجانب "بانتظار الشحن"
3. اضغط على التاب
4. ✅ يجب ظهور الطلبات الجاهزة للشحن فقط

### سيناريو 4: الاستثناءات
أضف طلبيات بـ:
- حالة "رد و يستلم" + ملاحظة "مرتجع" → ❌ لا تظهر في "بانتظار الشحن"
- حالة "رد و يستلم" + ملاحظة "مؤجل" → ❌ لا تظهر في "بانتظار الشحن"
- حالة "رد و يستلم" + ملاحظة "مراجعه" → ❌ لا تظهر في "بانتظار الشحن"

### سيناريو 5: البحث الشامل
1. اذهب لتاب "بدون حالة"
2. ابحث عن كود طلبية موجودة في تاب آخر
3. ✅ يجب ظهور الطلبية في نتائج البحث حتى لو مش في التاب الحالي

### سيناريو 6: العدد صفر
1. خلص جميع الطلبات "بدون حالة"
2. ✅ يجب ظهور "0" بلون رمادي بدون إشعار أحمر
3. ✅ التاب يبقى ظاهر (مش مخفي)

## 🎯 الفوائد

### 1. تنظيم أفضل
- الموظفة تقدر تشوف الطلبات اللي تحتاج action فوري بسهولة
- ما تضيع وقت في التدوير على الطلبات الجديدة

### 2. أولويات واضحة
- الإشعارات الملونة توضح إيه الأهم
- أحمر = طلبات جديدة (أولوية قصوى)
- برتقالي = جاهزة للشحن (متابعة مع المندوب)

### 3. إنتاجية أعلى
- الوصول السريع للطلبات المطلوبة
- تقليل الأخطاء والنسيان
- سهولة المتابعة

### 4. مرونة
- البحث الشامل يسمح بالعثور على أي طلبية بسرعة
- جميع التابات ظاهرة دائماً للمرجعية
