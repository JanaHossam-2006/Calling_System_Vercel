# ملخص: خاصية البحث للموظفات في الطلبات الحالية والأرشيفية

**التاريخ:** 7 سبتمبر 2026  
**الحالة:** ✅ مكتمل

---

## المطلب

إضافة خانة بحث للموظفات بحيث تقدر تبحث عن طلباتها (الحالية والأرشيفية) بدون تعقيد.

**الشرط الأساسي:** الموظفة تشوف فقط الطلبات المسجلة باسمها.

---

## الحل المطبق

### 1. Backend (Google Apps Script - Code.gs)

#### دالة جديدة: `employeeSearchOrders(employeeName, query)`
- **الموقع:** سطر 698 في `Code.gs`
- **الوظيفة:** بحث آمن للموظفات في طلباتهن فقط
- **المنطق:**
  1. جلب البيانات من شيت "البيانات"
  2. تفحص اسم الموظفة على كل طلب
  3. مقارنة البحث مع الكود ورقم العميل
  4. البحث في الأرشيف (فقط إذا لم تكن هناك نتائج)
  5. إرجاع النتائج مع علم `isHistorical`

**المثال:**
```javascript
// البحث عن طلبات Jana بكود "LOG-1001"
employeeSearchOrders("Jana Hossam", "LOG-1001")
// يرجع: [طلبات Jana فقط اللي تطابق البحث]
```

**الأمان:**
- ✅ فقط طلبات الموظفة (تفحص الاسم)
- ✅ معالجة الأرقام صحيحة
- ✅ معالجة التواريخ بشكل آمن
- ✅ حد أقصى للنتائج

### 2. Frontend (JavaScript.html)

#### تحديث 1: معالج البحث (search-code-input)
- **السطر:** 853
- **التغيير:** تفعيل البحث الديناميكي للموظفات
- **المنطق:**
  - إذا كانت موظفة عادية: استدعاء `employeeSearchOrders()`
  - إذا كانت مسؤولة متجر: البحث العادي (renderDashboard)

**الكود:**
```javascript
if (state.userRole === 'employee') {
    google.script.run
        .withSuccessHandler(function(data) {
            if (data.success) {
                state.lastEmployeeSearchResults = data.results;
                renderEmployeeSearchResults(data.results);
            }
        })
        .employeeSearchOrders(state.currentUser, searchQuery);
}
```

#### تحديث 2: دالة عرض النتائج
- **الموقع:** سطر 948
- **الدالة:** `renderEmployeeSearchResults(results)`
- **الميزات:**
  - عرض نتائج البحث بشكل منظم
  - شارة برتقالية للطلبات الأرشيفية
  - زر نسخ البيانات
  - زر إلغاء البحث

**البطاقة تحتوي على:**
- الكود (مع شارة أرشيف إذا لزم)
- رقم العميل
- المنتج والسعر
- المتجر
- حالة العميل والشحنة
- الملاحظات والتاريخ

#### تحديث 3: دالة النسخ

## سير العمل

```
1. الموظفة تفتح التطبيق
   ↓
2. تكتب في خانة البحث (كود أو رقم عميل)
   ↓
3. البحث يبدأ تلقائياً (input event)
   ↓
4. استدعاء employeeSearchOrders(اسمها، البحث)
   ↓
5. البحث في البيانات الحالية (مع التحقق من الاسم)
   ↓
6. إذا لا نتائج → البحث في الأرشيف
   ↓
7. النتائج ترجع مع isHistorical
   ↓
8. renderEmployeeSearchResults() تعرضها
   ↓
9. عرض البطاقات (حالي أو أرشيفي)
   ↓
10. الموظفة تقدر تنسخ أو تلغي البحث
```

## الأمان والحماية

✅ **التحقق من الملكية**
- اسم الموظفة يُفحص في كل نتيجة
- فقط طلبات تطابق الاسم تظهر

✅ **لا تعديل**
- الموظفة ترى البيانات فقط
- لا يمكن تعديل أو حذف
- فقط نسخ ومشاهدة

✅ **معالجة الأخطاء**
- استثناءات شاملة
- fallback للداشبورد العادي
- رسائل واضحة

## ملاحظات مهمة

⚠️ **للموظفات:**
- البحث حساس للكتابة (lowercase)
- الأرقام يجب تكون كاملة (01... مو 1...)
- الاسم يجب يكون صحيح تماماً في الشيت

⚠️ **للإدارة:**
- تأكد من تطابق أسماء الموظفات في الشيت
- الأسماء يجب تكون متسقة (مو "Jana" و "jana")
- الأرقام يجب تكون منسقة بشكل صحيح
