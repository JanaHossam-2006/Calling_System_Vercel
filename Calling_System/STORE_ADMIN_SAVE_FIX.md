# إصلاح مشكلة عدم حفظ الحالات والملاحظات في صفحة مسؤول المتجر

## النسخة: 2.3 (النهائي - خالي من الأخطاء)

---

## المشكلة
صفحة مسؤول المتجر لم تكن تحفظ:
- ✗ حالة التبليغ ("تم" / "لم يتم" / "طلب جديد" / "إعادة إرسال")
- ✗ ملاحظات المسؤول

---

## السبب الجذري
الأعمودان "تبليغ المسؤول" و "ملاحظه المسؤول" موجودان في الأعمدة **V و W** (الفهارس 21 و 22)، لكن الكود كان يحاول الكتابة والقراءة من أعمدة خاطئة.

---

## الإصلاحات المطبقة

### 1. Code.gs - setupDatabase() [السطر 25-29]
إعادة ترتيب الأعمدة بحيث تكون 5 أعمدة فارغة قبل "حالة المرتجع"، ثم الأعمودان الجديدان:

```javascript
const dataHeaders = [
  'الاسم', 'كود الطلب', 'رقم العميل', 'رقم المندوب', 'اسم المنتج', 
  'السعر', 'المتجر', 'ملاحظة', 'عدد مرات الاتصال', 'الحالة - العميل', 
  'أكثر من 5 محاولات', 'ملاحظة - العميل', 'الحالة - الشحنه', 'ملاحظة - المندوب', 'التاريخ',
  '', '', '', '', '', 'حالة المرتجع', 'تبليغ المسؤول', 'ملاحظه المسؤول'
];
```

### 2. Code.gs - getAdminDashboardData() [السطر 412-414]
تصريح صحيح لـ COL_REPORT و COL_STORE_NOTE:

```javascript
const COL_REPORT = idx('تبليغ المسؤول', 21);
const COL_STORE_NOTE = idx('ملاحظه المسؤول', 22);
```

### 3. Code.gs - حذف التصريح المكرر [السطر 472]
تم حذف السطر التالي الذي كان يسبب خطأ "Identifier already declared":

```javascript
// ❌ تم حذف:
const COL_REPORT = idx('تبليغ المسؤول', 15);
```

### 4. Code.gs - getOrdersData() [السطر 239-241]
قراءة البيانات من الأعمدة الصحيحة:

```javascript
order['تبليغ المسؤول'] = row[21] !== undefined ? row[21] : '';
order['ملاحظه المسؤول'] = row[22] !== undefined ? row[22] : '';
```

### 5. Code.gs - handleStoreActionBackend() [السطر 980-996]
استخدام الفهارس الصحيحة (21 و 22):

```javascript
let reportCol = headers.indexOf('تبليغ المسؤول');
let noteCol = headers.indexOf('ملاحظه المسؤول');

if (reportCol === -1) reportCol = 21;  // V
if (noteCol === -1) noteCol = 22;      // W

sheet.getRange(rowIndex, reportCol + 1).setValue(statusValue);
sheet.getRange(rowIndex, noteCol + 1).setValue(note);
```

## جدول الأعمدة النهائي

| الفهرس | الحرف | الاسم |
|--------|------|------|
| 0-14 | A-O | الأعمدة الأساسية (15 عمود) |
| 15-19 | P-T | فارغة (5 أعمدة) |
| 20 | U | حالة المرتجع |
| **21** | **V** | **تبليغ المسؤول** ✅ |
| **22** | **W** | **ملاحظه المسؤول** ✅ |

---

## النتائج

✅ حالة التبليغ تُحفظ في العمود V  
✅ الملاحظات تُحفظ في العمود W  
✅ لا توجد أخطاء Syntax  
✅ لا توجد تصريحات مكررة  
✅ جميع الفهارس صحيحة
