# تحديث واجهة مراقبة المتاجر للمديرة

## التغييرات المطلوبة

### 1. عرض إجمالي الطلبات بدلاً من المتبقي
**قبل:** كان يظهر "X طلب متبقي" (فقط الطلبات المتبقية)  
**بعد:** يظهر "X طلب إجمالي" (تم + لم يتم + متبقي)

### 2. إخفاء الفئات الفارغة
**قبل:** كانت جميع الفئات (عادي، مرتجع، مؤجل، استبدال) تظهر دائماً حتى لو كانت فارغة  
**بعد:** تظهر الفئة فقط إذا كان فيها طلبات

## التعديلات المطبقة

### في JavaScript.html - دالة `renderAdminStores()`

#### 1. حساب إجمالي الطلبات
```javascript
// حساب إجمالي الطلبات (تم + لم يتم + متبقي)
const totalStoreOrders = (s.done || 0) + (s.notDone || 0) + (s.pending || 0);
```

#### 2. تغيير العرض في الواجهة
```javascript
// قبل:
<span>...${s.pending} طلب متبقي</span>

// بعد:
<span>...${totalStoreOrders} طلب إجمالي</span>
```

#### 3. إخفاء الفئات الفارغة
```javascript
const getBadge = (label, count, activeColor) => {
    // إخفاء الفئة إذا لم يكن فيها طلبات
    if (!count || count === 0) return '';
    
    if (count > 0) {
        return `<span>...${label}: ${count}</span>`;
    }
    return '';
};
```

#### 4. إخفاء صندوق الفئات بالكامل إذا كانت كلها فارغة
```javascript
// بناء badges الفئات
const badges = [
    getBadge('عادي', s.pendingNormal, '#94a3b8'),
    getBadge('مرتجع', s.pendingReturned, 'var(--accent-rose)'),
    getBadge('مؤجل', s.pendingPostponed, 'var(--accent-amber)'),
    getBadge('استبدال', s.pendingExchange, 'var(--accent-emerald)')
].filter(b => b !== '').join('');

// إخفاء صندوق الفئات إذا لم يكن هناك أي فئات
const categoriesSection = badges ? `
    <div style="...">
        ${badges}
    </div>` : '';
```

## النتيجة

### مثال 1: متجر فيه طلبات من كل الفئات
```
┌─────────────────────────────────┐
│ متجر التقنية    [15 طلب إجمالي]│
├─────────────────────────────────┤
│  تم: 5  │ لم يتم: 3 │ متبقي: 7  │
├─────────────────────────────────┤
│ عادي: 4 │ مرتجع: 2 │ مؤجل: 1   │
└─────────────────────────────────┘
```

### مثال 2: متجر فيه فئة واحدة فقط
```
┌─────────────────────────────────┐
│ متجر الأزياء    [8 طلب إجمالي] │
├─────────────────────────────────┤
│  تم: 3  │ لم يتم: 1 │ متبقي: 4  │
├─────────────────────────────────┤
│ عادي: 4                         │
└─────────────────────────────────┘
```

### مثال 3: متجر خلص كل الطلبات
```
┌─────────────────────────────────┐
│ متجر الإلكترونيات [10 طلب إجمالي]│
├─────────────────────────────────┤
│  تم: 8  │ لم يتم: 2 │ متبقي: 0  │
├─────────────────────────────────┤
│ (لا توجد فئات متبقية)           │
└─────────────────────────────────┘
```

## الفوائد

✅ **وضوح أكثر**: المديرة تشوف إجمالي الشغل اللي المتجر عمله  
✅ **واجهة نظيفة**: الفئات الفارغة ما بتظهرش  
✅ **سهولة المتابعة**: تركيز على الفئات النشطة فقط  
✅ **معلومات دقيقة**: الأرقام واضحة ومباشرة
